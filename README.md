# Smart Visitor Tracking System 🚗🕒

A Python & Django-based backend application designed to automate, verify, and log visitor entries securely using computer vision metrics and structured relational storage.

## 🚀 Features
- **Automated Logging:** Tracks vehicle entry/exit using data extracted from image directories.
- **Identity Verification:** Cross-references visitor processing matches with pre-approved records.
- **Robust Database Layer:** Powered by structured storage backend logic for efficient historical lookups.

## 🛠️ Tech Stack
- **Language:** Python 3.x
- **Framework:** Django (`manage.py` application architecture)
- **Data & Processing:** OpenCV, Pandas, SQLite / Relational Database

## 📁 Installation & Local Setup
To run this project locally, clone the repository and install the dependencies:
```bash
git clone https://github.com
cd Visitor-Tracking-App
pip install -r requirements.txt
python manage.py runserver
```
